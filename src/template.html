My 3-Day Strength Plan

Full-body workouts for back, arms and legs. No bench or table needed, and a mat-sized space is enough. Pick today's workout (for example Mon / Wed / Fri).

How to run each workout
  • Pairs: exercises with the same number (1A and 1B) are done back to back. Do A, rest 30 seconds, do B, then rest 60–90 seconds. Repeat for all sets.
  • Weeks 1–2: do only 2 sets of each exercise with light weights. Learn the moves first. Some soreness is normal.
  • Picking weight: choose one where the last 2–3 reps feel hard but your form stays clean.
  • Moving up: when you hit the top rep number on every set, use heavier dumbbells or a thicker band.
  • Off days: a 20–30 minute walk helps fat loss and recovery.
Using your band platform
  • The platform is optional. Start with the dumbbell versions, and bring in the platform when you want more resistance or your dumbbells feel too light.
  • Stand on it, attach a band the way the platform's instructions describe, and hold the handles or bar.
  • Exercises with a blue "Platform option" box can be done this way.
  • Check bands for nicks or wear before each use.
  • Door anchor: use the top of a door that opens away from you, close it fully, and tug-test it before each set.
